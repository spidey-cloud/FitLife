# Bundled fonts

The app bundles these typefaces in `app/src/main/res/font/` (static TTF instances,
taken from the `@expo-google-fonts/*` npm packages, which redistribute Google Fonts).
All are licensed under the **SIL Open Font License 1.1** — see the `*-OFL.txt` files here.

| Typeface | Used by | Files |
|---|---|---|
| Plus Jakarta Sans | Kinetic Clarity (light theme) — all text | `jakarta_*.ttf` |
| Space Grotesk | Night Ride (dark theme) — display & headlines | `spacegrotesk_*.ttf` |
| Geist | Night Ride — body & titles | `geist_*.ttf` |
| JetBrains Mono | Night Ride — labels / numbers | `jetbrainsmono_*.ttf` |
